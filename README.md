# Resource pack search in the Windows Horizon launcher

Actual windows of the launcher built from PR #19305 commit `ba5bbef0950055259a7afc7cb2ccfd5d12d3fecd`. The tested executable had SHA-256 `9111bd4e4cc614d40ea55111d314f787c49f4a566b283182f7ed1df00e95d299`. [Windows build](https://github.com/RLC248/horizon/actions/runs/45072558371).

This used a fresh launcher home, a Horizon instance and live Modrinth results. On the Resource Packs tab, Modrinth was selected and Show everything was off throughout.

1. Opening the tab displayed Fresh Animations, Chat Reporting Helper and Low On Fire.
2. Typing `glass` and pressing Enter displayed Glass, Clean Connected Glass and Borderless Glass.
3. Pressing Backspace five times returned Fresh Animations, Chat Reporting Helper and Low On Fire. No Enter key was pressed after clearing the query.

The three original window captures use the system's German interface.
